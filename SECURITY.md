# Security policy

Please report vulnerabilities privately through [GitHub's reporting form](https://github.com/bigint/meridian/security/advisories/new). Do not open a public issue.

Include the version, a description and the steps to reproduce. We aim to acknowledge reports within three working days, and we'll keep you informed until a fix ships.

## Supported versions

Fixes land on `main` and in the next release. Only the latest release is supported.

How Meridian is meant to be deployed and what it protects is described in [docs/operate/security.mdx](docs/operate/security.mdx).
