# Security policy

Please report vulnerabilities privately to **security@meridian.example** (replace with the project's real address before publishing). Do not open a public issue.

Include the version, a description and the steps to reproduce. We aim to acknowledge reports within three working days, and we'll keep you informed until a fix ships.

How Meridian is meant to be deployed and what it protects is described in [docs/security.md](docs/security.md).
