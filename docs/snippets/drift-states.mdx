| State | Mark | Means |
| --- | --- | --- |
| In sync | `✓` | Running exactly the version Git says. |
| Drifted | `≠` | Running, but not the version Git says. For example, a deploy is still rolling out, or it stopped part-way. |
| Missing | `✕` | Git says it should run here, but nothing is running. |
| Stray | `?` | Running here, but Git doesn't put it here. |
| Stale | `…` | The server's agent has gone quiet, so Meridian can't tell what runs there right now. |
| Unknown | `–` | Nothing to compare yet: the server has no agent, or the app has no version file. |

On the board, each cell shows the version it runs. A missing cell shows `✕`, a drifted cell shows `≠` and the version, and an unknown cell shows `–`. A stray cell has a dotted border, and a stale or unknown cell has a dashed border.
