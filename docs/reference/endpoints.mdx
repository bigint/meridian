This page lists every address Meridian answers. Four are endpoints for machines. Everything else is an HTML page that needs you to be signed in, through the session cookie.

| Endpoint | Caller | Auth |
| --- | --- | --- |
| `POST /agent/snapshots` | The agent | `Authorization: Bearer <agent token>` |
| `GET /cable` | The agent and browsers | Agent token, or the session cookie |
| `GET /up` | kamal-proxy and monitors | None |
| `/jobs` | You, in a browser | The session cookie |

## POST /agent/snapshots

A snapshot: what runs on one server. The [agent](/reference/glossary#agent) sends one every 15 seconds by default. Meridian checks it, queues it, and answers `202`.

- Meridian refuses a body over 1 MiB with `413`, before Rails reads it.
- Each token can send 120 a minute.
- A fleet token can send 120 a minute for each machine ID, and 12,000 a minute in all.

See [Agent protocol](/reference/agent-protocol#snapshots) for the fields and every status code.

## GET /cable

Rails' Action Cable WebSocket, a connection that stays open so Meridian can push updates. Two kinds of client connect to it:

| Client | Auth | Channels |
| --- | --- | --- |
| The agent | `Authorization: Bearer <agent token>`. A connection with this header never falls back to a cookie. | `AgentChannel` |
| A browser | The signed `session_id` cookie | Turbo Streams for live pages, `ServerStatsChannel`, `LogsChannel`, `TrafficChannel` |

Live pages refresh through Turbo Streams: the board, the map and an app's page. Stats, logs and traffic stream through their own channels.

Logs and traffic need a grant. The logs or traffic page creates that grant when it loads, for exactly what it shows, and it lasts 12 hours. When you sign out, or change your password and end your other sessions, Meridian closes those sessions' open connections.

See [Agent protocol](/reference/agent-protocol#the-live-line).

## GET /up

Rails' health check. It answers `200` when the app has started, and `500` when it failed to start.

- It needs no sign-in.
- It skips forced HTTPS and the `MERIDIAN_URL` host check.
- Meridian leaves it out of the logs.

[kamal-proxy](/reference/glossary#kamal-proxy) calls it by IP address before it sends traffic to a new container.

```bash
curl -fsS https://meridian.example.com/up
```

## /jobs

Mission Control Jobs, the dashboard for Meridian's background jobs in Solid Queue. It shows queues, running, failed and scheduled jobs, and recurring tasks.

It needs you signed in. The sidebar links to it as **Jobs**.

## Pages

Every other address is a page for you, in a browser. The rate limits in the **What it is** column count requests from one IP address. Every page except the last two needs you signed in. A request from someone not signed in goes to `/session/new`.

| Path | What it is |
| --- | --- |
| `/` | The board |
| `/jump?q=` | Search: apps, servers and projects, the best 8 |
| `/map` | The map |
| `/apps`, `/apps/:id` | Apps and an app's page |
| `/apps/new` | New app |
| `POST /apps/:id/deploys` | Deploy a version. 10 a minute. |
| `POST /apps/:id/rollbacks` | Roll back the newest release. 10 a minute. |
| `POST /apps/:id/redeploy` | Run CI again for the version in Git. 5 a minute. |
| `/apps/:id/log` | An app's logs, merged across its servers |
| `/apps/:id/traffic` | An app's requests, from kamal-proxy |
| `/placements/:id/log` | One container's logs |
| `/servers`, `/servers/:id` | Servers and a server's page |
| `/traffic` | Every app's requests, from kamal-proxy |
| `PATCH /servers/:id` | Set a server's location |
| `/events` | Activity |
| `/secrets` | Secret names per project |
| `POST /secrets`, `PATCH /secrets/:id` | Add a name, set a value. 20 a minute. |
| `/tunnels`, `/tunnels/setup` | Tunnels and tunnel setup |
| `/tunnels/connectors/edit` | Edit connectors |
| `/agents` | Agent tokens and silent servers |
| `POST /agents`, `DELETE /agents/:id` | Create and revoke tokens |
| `/projects`, `/projects/:id` | Projects and a project's page |
| `/projects/new`, `/projects/:id/edit` | Add and edit a project |
| `POST /projects/:id/sync` | Sync now |
| `POST /projects/:id/workflow` | Add CI workflow |
| `/settings` | Settings |
| `PATCH /settings/account` | Save where Meridian runs |
| `PATCH /settings/user` | Save your name, email address and password |
| `/session/new` | Sign in. 10 tries in 3 minutes. No sign-in needed. |
| `/first_run` | Create your account, with the setup code. Once the account exists, it sends you to the board. No sign-in needed. |

## No general API

Meridian has no REST or GraphQL API, and no API tokens for you. This is on purpose:

- Git is the interface for changes. To deploy from a script, commit the version file. Meridian sees the commit and CI deploys it, exactly as if someone pressed **Deploy**.
- Agent tokens work only on `/agent/snapshots` and `/cable`. They can't read or change anything else.
- Pages check the session cookie and a CSRF token, so another site can't drive them.
